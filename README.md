# 📘 **README — Прогрессивный шифр Виженера**

### 📌 **О проекте**
Десктопное приложение на фреймворке [Wails](https://wails.io) для шифрования и дешифрования текста на **русском языке** с использованием **прогрессивного шифра Виженера**.  
Ключевая особенность: каждая буква ключа **увеличивается на 1** после использования, что делает шифр более устойчивым к частотному анализу.

---

### ✨ **Особенности**
- ✅ Поддержка **русского алфавита** (33 буквы, включая **Ё**)
- 🔄 Прогрессивное изменение ключа
- 📂 Загрузка текста из файла и сохранение результата
- 🖥️ Простой и понятный интерфейс на русском языке
- 🔒 Автоматическая фильтрация недопустимых символов (только буквы А–Я и Ё)

### 🔐 **Где реализована основная логика**

**Весь криптоалгоритм находится в `app.go`:**

| Метод | Описание |
|-------|----------|
| `Encrypt(plaintext, key)` | Шифрование с прогрессивным ключом (возвращает строку) |
| `Decrypt(ciphertext, key)` | Дешифрование |
| `OpenFile()` | Открытие файла и чтение содержимого (только русские буквы) |
| `SaveFile(content)` | Сохранение результата в файл |

**Принцип работы:**
- Алфавит задан константой `RussianAlphabet = "АБВГДЕЁЖЗИЙКЛМНОПРСТУФХЦЧШЩЪЫЬЭЮЯ"`.
- Каждая буква текста и ключа преобразуется в индекс (0–32).
- Для шифрования: `(индекс_буквы + индекс_ключа) % 33`.
- Для дешифрования: `(индекс_буквы – индекс_ключа) % 33` (с коррекцией отрицательных значений).
- После обработки одного символа текущая буква ключа **увеличивается на 1** (индекс сдвигается по алфавиту циклически).
- Затем переход к следующей букве ключа (циклически по длине ключа).

### 🛠 **Сборка и запуск**

#### Требования:
- Go 1.18+
- Node.js 16+
- Wails CLI (`go install github.com/wailsapp/wails/v2/cmd/wails@latest`)

#### Команды:
```bash
# Установка зависимостей фронтенда
cd frontend
npm install
cd ..

# Сборка приложения
wails build

# Готовый исполняемый файл появится в папке build/bin/
```

### 📋 **Требования к вводу**
- Только русские буквы (А–Я, а–я, Ё, ё).
- Регистр не важен — всё приводится к верхнему.
- Ключ может быть любой длины (но не пустой).
- Пробелы, цифры и спецсимволы автоматически удаляются из ввода.
